# Sqoch-TZ — Neon Waves: оформление билетов

## Запуск

Нужен Node.js 20.19+ или 22.12+ (проверено на 24).

```bash
git clone https://github.com/Prostotatik/Sqoch-TZ.git
cd Sqoch-TZ
npm install
npm run dev        # http://localhost:5173
```

Прочие команды:

```bash
npm run build      # typecheck + production-сборка в dist/
npm run preview    # локальный просмотр сборки
npm test           # unit-тесты (vitest)
npm run typecheck  # только проверка типов
```

Демо-сценарии (query-параметры):

- `?scenario=soldout` (или `?soldout=1`) — места заканчиваются прямо перед подтверждением;
- `?scenario=partial` — мест меньше, чем участников в заказе.

Переключатель сценария есть и на шаге подтверждения.

## Стек

- **React 19** + **TypeScript**, сборка **Vite**
- **Zustand** — состояние заказа
- **Motion** — анимации, **Lenis** — плавный скролл, **@number-flow/react** — анимация цен
- **three.js** / **@react-three/fiber** / **drei** / **postprocessing** — 3D-сцена (только десктоп, ленивая загрузка)
- **lucide-react** — иконки, **uqr** — QR-код билета
- Шрифты: Unbounded, Onest, Bad Script (@fontsource)
- **Vitest** — тесты доменной логики, валидации, API-моков и стора
- Деплой: **Vercel**

## Что реализовано

Покупка билетов на мероприятие на моковых данных:

- 1–4 участника в заказе; полный билет 2000 ₽ (от 14 лет), детский 1000 ₽ (младше 14);
- ребёнок допускается только вместе с участником от 18 лет в том же заказе;
- имя и возраст для каждого участника, один email на заказ;
- экран проверки состава заказа и итоговой суммы с возможностью правки до подтверждения;
- экраны успешного оформления и «места закончились»;
- адаптив под компьютер и телефон, поддержка `prefers-reduced-motion`.

## Структура

```
src/
  app/         корневой компонент
  screens/     лендинг, шаги оформления, финальные экраны
  components/  UI, эффекты, 3D
  domain/      правила, цены, валидация, места (чистая логика + тесты)
  data/        событие, мок-API, генерация .ics
  state/       zustand-стор заказа
  styles/      токены и стили
public/assets/ изображения
```
